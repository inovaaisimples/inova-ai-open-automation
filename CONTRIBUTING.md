# Contributing / Como contribuir

Obrigado por melhorar automações abertas e seguras.

1. Não envie segredos, tokens, URLs privadas, dados pessoais ou dados de clientes.
2. Use exemplos fictícios (`example.com`, nomes genéricos) e documente pré-requisitos.
3. Valide JSON com `jq empty arquivo.json` e importe o workflow em uma instância de teste do n8n.
4. Descreva impacto, teste realizado e considerações de segurança no pull request.
5. Mantenha mudanças pequenas, portáveis e independentes de fornecedores quando possível.
